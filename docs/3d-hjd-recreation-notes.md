### 二、如何在你本地运行新版本？

直接在线试玩：你现在可以直接点击当前页面生成的 预览窗口（Canvas），点击「开始对局」体验发牌升降机、拖拽出牌、抛物线飞牌和吃碰杠特效。

下载完整工程到本地：

点击我上一条回复里的 cs-mahjong-3dhjd.zip 下载压缩包。

解压覆盖你本地的 cs-mahjong 文件夹，在终端运行：

```bash
npm install
npm run dev
```


（可选）挂载本地解包的 .ogg 原声语音包：

由于浏览器端代码体积限制，我在 src/utils/audio.js 里内置了 Web Speech 长沙话台词与物理骨牌合成音，同时预留了原版音频挂载接口。

如果你想直接听 D:\4a volcano 里的真人录音，只需用 AssetStudioGUI 打开你刚才打包的 announcementvoice_assets_all_8bc66c6a9c7a45c1917aecc579c4f246.bundle 和 audiodatabaseclips_assets_all_910d3ae7702b4c7335bea6e46b2d01fe.bundle，把导出的 .ogg 文件放进项目的 public/hjd-audio/ 目录，游戏就会自动切换为 100% 原版真人配音。

你先在预览窗口或者本地跑一下试试，看看桌面透视角度、牌面大小、出牌飞行速度哪块还不合心意，直接告诉我，我随时帮你微调参数！
