# 长沙麻将 · 计分规则（玩家向完整说明）

> 本文件是**面向玩家**的计分规则说明，与 `src/utils/scoring.js`（唯一实现）逐条对应。
> 实现审计与实现进度见 `docs/SCORING.md`；代码实现核对见 `docs/RULES.md`。
> 术语：**庄位**指「本次计分时的庄」（不是上一局的庄），见下文 §2。

---

## 1. 符号与参数

| 符号 | 含义 | 取值 |
|---|---|---|
| **B** | 基础分 | 房间规则自定：整数 1–100（默认 1） |
| **F** | 固定分 | 房间规则自定：整数 0–100（默认 1，可为 0） |
| **k** | 本次胡牌所含**大胡番型个数** | k ≥ 1（大胡）；平胡 k = 0 |
| **n** | 某位付分者对应的**中鸟个数**（逐家单独统计） | 0..抓鸟数 |
| **M** | 鸟翻倍乘数 = n + 1 | 没中鸟时 M = 1 |
| **CAP** | 封顶 = 6 × 7B = **42B** | 固定不可配；2F 不参与封顶 |

联机时 B/F 由房主设定、同步给所有人，**开局后锁定**。

## 2. 庄家（计分庄）怎么定

1. 谁胡牌，本次计分时谁就是庄（自摸、点炮都一样）。
2. 起手胡、中途四喜：**触发者**就是该次结算的庄。
3. 通炮（一炮多响）：**放炮者**是庄。
4. 流局：**最后一张牌由谁摸，谁就是庄**；流局不计分。
5. 下一局的庄 = 本局终局结果按上述规则确定的庄；**起手胡、中途四喜的结算不影响下一局的庄**。

## 3. 计分公式

```
小胡：Base = 2B
大胡：Base = 7B × k        （每多一个大胡番型加 7B，是线性相加，不是翻番）

某位付分者应付：
P = min( Base × (n+1), 42B ) + 2F
```

- **封顶**：叠加番型与鸟翻倍后的金额超过 42B 时一律截断为 42B，再加 2F。**单家应付最高 42B + 2F**。
- **2F 不参与叠加、不参与翻番、不受封顶**，最后相加。
- 没中鸟（n = 0）时 M = 1，即按底分付。

## 4. 谁付、付多少

| 方式 | 赔付 |
|---|---|
| **自摸** | 另外三家分别按各自的 n 算 P，三家相加 = 胡牌者总得分 |
| **点炮** | **只有放炮者付 P**，其余两家不付 |
| **通炮（一炮多响）** | 每位胡牌者按各自牌型、各自的 k 与 n 单独结算；放炮者总付 = ΣP；**放炮者做庄** |
| **起手胡 / 中途四喜** | 按自摸记分（三家分别算、再相加） |

**全局零和**：所有玩家本局得失分之和恒为 0。

## 5. 中鸟数 n 怎么算

鸟点对应座位（以**计分庄位**为基准）：

| 鸟点 | 对应座位 |
|---|---|
| 1 / 5 / 9 | 庄位 |
| 2 / 6 | 庄位下家 |
| 3 / 7 | 庄位对家 |
| 4 / 8 | 庄位上家 |

`n = 落在「有效座位」上的鸟数`，有几个算几个（同座位被多只鸟命中可累加）：

| 方式 | 有效座位 |
|---|---|
| 自摸 | 庄位（胡牌者）+ **当前这一位付分者** → 三家各算一次，得到三个 n |
| 点炮 | 庄位（胡牌者）+ 放炮者 |
| 通炮 | 庄位（放炮者）+ 当前正在结算的那位胡牌者 |
| 起手胡 / 中途四喜 | 同自摸（庄位 = 触发者，逐家计算） |

**抓鸟数量**沿用规则设置（0 / 2 / 4 只；0 表示不抓鸟，n 恒为 0）。

### 抓鸟方式

- **终局胡牌**：翻牌墙，取**牌墙末尾**的 N 张并移除该牌（与开杠补牌同侧）。
- **起手胡 / 中途四喜**：不翻牌墙，**摇骰子**。骰子数量 = 规则设置里的抓鸟数；点数直接当鸟点（六面骰只有 1–6，因此只会命中庄位/下家/对家/上家，不会出现 7/8/9）。
- 骰子由**权威端（房主/服务端）用安全随机源**生成，客户端只展示动画与结果。

## 6. 番型归类

| 归类 | 番型 |
|---|---|
| **小胡**（k = 0） | 平胡（二五八做将）、起手胡（大四喜/板板胡/缺一色/六六顺）、中途四喜 |
| **大胡**（每项 +7B，计入 k） | 清一色、将将胡、碰碰胡、全求人，以及杠上开花、杠上炮、海底捞月、海底炮等特殊番种 |

- 同时成立的大胡番型**各算一个**（例：清一色 + 碰碰胡 → k = 2 → Base = 14B）。
- 大胡成立时不再按小胡算。
- 起手胡、中途四喜每一次都按一次小胡**独立结算**，不与终局胡牌合并。

## 7. 起手胡与中途四喜

1. 起手胡在开局发牌后检测；每个起手胡各摇一次骰子、各自独立结算。
2. 中途四喜：行牌中摸牌后手里凑成 4 张相同的牌即算胡（小胡），触发者为该次结算的庄，按自摸记分并摇骰子抓鸟。
   - 每一组不同的 4 张牌各触发一次，同一组只触发一次。
   - 触发后若把这 4 张开杠，已结算的分数不撤销，杠本身按杠牌规则处理。
   - 结算后**牌局继续**，不结束本局，触发者仍可继续行牌并正常胡牌。
3. 规格外的 6 种起手胡（一个五 / 三个五三个八 / 三连对 / 三同 / 二筒二条）**默认关闭**，可在「规则设置」里打开；打开后同样按小胡自摸结算。

## 8. 验算示例（B = 1，F = 1，CAP = 42）

| # | 场景 | 结果 |
|---|---|---|
| 1 | 小胡自摸，三家 n = 0 | 每家 2+2 = **4**，胡牌者共得 **12** |
| 2 | 小胡点炮，n = 2 | P = 2×3+2 = **8**，只有放炮者付 |
| 3 | 大胡点炮，k = 1，n = 0 | P = 7+2 = **9** |
| 4 | 大胡自摸，k = 1，三家 n = 1/1/0 | P = 16 / 16 / 9，共得 **41** |
| 5 | 大胡点炮，k = 3，n = 1 | 21×2 = 42（未超顶）→ P = **44** |
| 6 | 通炮：A 小胡 n=0，B 大胡 k=1 n=1 | A 得 4、B 得 16，放炮者共付 **20** |
| 7 | 小胡自摸，4 只鸟点为 1、5、3、2（庄位 = 胡牌者） | 下家 n=3→10，对家 n=3→10，上家 n=2→8，共得 **28** |
| 8 | 清一色 + 碰碰胡（k=2）自摸，n = 0 | 每家 14+2 = **16**，共得 **48** |
| 9 | 封顶：k=4,n=1 → 56；k=2,n=3 → 56；k=7,n=0 → 49；k=6,n=0 → 42 | 前三例封顶 **P = 44**；第四例刚好等于封顶 P = **44** |
| 10 | 起手胡（板板胡）摇 2 颗骰子 = 4、1（庄位 = 触发者） | 下家 n=1→6，对家 n=1→6，上家 n=2→8，触发者共得 **20** |
| 11 | 中途四喜摇 2 颗骰子 = 6、3（庄位 = 触发者） | 下家 n=1→6，对家 n=1→6，上家 n=0→4，触发者共得 **16** |

> 示例 11 说明：规格原文写「对家 n=1+1=2、共得 18」，但两颗骰子 6、3 分别落「下家、对家」，按 §5 的有效座位口径（{庄位, 该付分者}）对家只有 1 只鸟。**已按规格 §5 的公式裁定为 16**，其余 10 个示例与规格完全一致（`test/scoring.test.js` 逐条断言）。

## 9. 界面在哪里看这些数

- **规则设置**面板：基础分 B / 固定分 F（并显示当前封顶值 42B）、开杠摸牌数、开杠需将、起手胡类型、抓鸟数量。
- **起手胡 / 中途四喜**：即时提示，显示骰子点数、逐家 n 与乘数、封顶前后的金额与是否封顶、每家应付；不打断牌局。
- **结算页**：番型与 k、B/F、逐家 n 与乘数、封顶前金额与是否封顶、每家应付、四家得失、抓鸟结果、新庄是谁。
