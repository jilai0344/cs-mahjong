# 长沙麻将 · 现代清澈版 (Changsha Mahjong)

一款基于 React 19 + Tailwind CSS + Web Audio API 打造的高品质**长沙麻将**网页游戏。

界面设计遵循**现代、简洁、清澈**的美学理念，还原真实的翡翠琉璃毛毡桌面、象牙白骨牌、清脆低延迟麻将撞击音效与生动的出牌/碰杠动效，并提供全套深度可配置的长沙麻将特色规则。

---

## 🌟 核心特色与用户定制规则

根据玩家需求深度定制，支持在游戏顶部**「规则设置」**面板中随时自由调整：

### 1. 开杠摸牌数设置 (2只 vs 4只)
- **开杠摸 2 只（标准长沙）：** 开杠（暗杠/明杠/补杠）后从牌墙末尾补牌摸出 2 张牌。
- **开杠摸 4 只（加量刺激）：** 开杠后一次性摸出 4 张牌。
- **杠牌流转机制：** 摸出的牌若本人能成胡则直接触发**杠上开花**；若未能成胡，所有摸出的牌将全部打入牌池，其他玩家均可点炮成胡（**杠上炮**，支持一炮多响）。

### 2. 开杠需不需要将设置
- **开杠需要将（严格传统长沙规则）：** 玩家手牌中必须保留有 **2、5、8** 作为将牌储备方可开杠。若手中没有 2、5、8，系统将智能拦截开杠动作，保证牌型合规。
- **开杠免将（自由休闲规则）：** 只要凑齐 4 张相同牌即可任意开杠，不限制手牌是否持有将牌。

### 3. 起手胡牌（小胡）自主勾选
开局发牌完毕（庄家 14 张，闲家 13 张）后，即时扫描并弹出**起手胡牌祥瑞通知**，各家计分后继续正常行牌：
- ☑ **大四喜**：起手手牌拥有 4 张完全相同的牌。
- ☑ **板板胡**：起手手牌没有任何一张 2、5、8 将牌。
- ☑ **缺一色**：起手手牌缺少某一门花色（仅有两门或一门）。
- ☑ **六六顺**：起手手牌拥有两组刻子（即两组各有 3 张相同牌）。

### 4. 终局扎鸟（抓鸟）配置
- 支持设置 **不抓鸟 (0只)**、**标准抓 2 鸟**、**豪迈抓 4 鸟**。
- 按胡牌者座位顺位根据鸟牌点数（1/5/9 为赢家中鸟，2/6 下家，3/7 对家，4/8 上家）精准计算翻倍奖励。

### 5. 纯正长沙麻将胡牌算法
- **平胡：** 严格遵循**“二五八做将”**核心规则，将牌必须为二、五、八。
- **经典大胡（乱将）：**
  - **清一色：** 全手牌为同一种花色（6番）。
  - **将将胡：** 手牌与副露全部由 2、5、8 组成，无需顺子（6番）。
  - **碰碰胡：** 全由刻子加一对将组成（6番）。
  - **全求人：** 4副牌全亮，单吊一张放炮胡牌（6番）。
  - **杠上开花 / 杠上炮 / 海底捞月 / 海底炮** 等特殊番种。

## 🎨 现代清澈视听设计

- **纯澈翡翠牌桌：** 深邃渐变翡翠毛毡桌面，经纬暗纹与环形氛围微光，居中集成东南西北方位罗盘、倒计时轮盘与牌墙计数。
- **微立体 3D 骨牌：** 象牙白温润骨面配合青翠玉石衬背，万、条、筒矢量精致呈现（特别重绘 1 条灵动翠鸟与 1 筒经典大花轮）。
- **智能辅助对局：**
  - 智能听牌分析气泡：选牌时即时显示听哪些牌、各剩多少张。
  - 悬停关联高亮：鼠标悬停手牌时，桌面所有相同牌张柔和高亮，算牌查牌一目了然。
  - 最新出牌聚焦光环与超时自动托管。
- **全离线 Web Audio 音效：** 模拟真实高密度密胺麻将击打桌面、摸牌轻碰、吃碰杠和弦、胡牌胜利 fanfare，零延迟无网络依赖。

## 🚀 启动与体验指南

### 1. 启动本地开发服务
```bash
npm run dev
```
打开浏览器访问控制台提示的本地链接（例如 `http://localhost:5173`）即可全屏畅玩。

### 2. 运行自动化单元测试
```bash
npm test
```
执行 15 项长沙麻将核心算法逻辑测试（涵盖起手胡、开杠需将限制、平胡258将校验、大胡番型及扎鸟算法）。

### 3. 构建发布包
```bash
npm run build
```
构建产物输出至 `dist/` 目录。
